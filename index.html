Fitur Unggulan Sistem EcoWaste

Dibangun dengan standar rekayasa perangkat lunak modern untuk performa dan keamanan data tinggi.

💳

Double-Entry Ledger Saldo

Saldo nasabah tidak disimpan sebagai angka biasa, melainkan dihitung otomatis dari mutasi riil: SUM(kredit) - SUM(debit) di tabel SaldoLog.

🛡️

Anti-Race Condition Guard

Pada approval penukaran poin, sistem melakukan re-check saldo di dalam database transaction sebelum mutasi debit dibuat agar saldo nasabah tidak pernah minus.

📸

Bukti Foto Timbangan Fisik

Setiap transaksi setoran sampah dilengkapi foto timbangan fisik mandiri (Base64/SVG Data URL) yang dapat dipratinjau melalui popup modal baik oleh warga maupun admin.

🔐

Password Hashing SHA-256

Tidak ada kata sandi yang disimpan plaintext. Seluruh autentikasi menggunakan enkripsi hash bawaan Node.js crypto stdlib tanpa dependensi rentan.

📦

Input Setoran Multi-Row

Form transaksi Bento Grid modern memungkinkan petugas menimbang dan mencatat berbagai jenis sampah sekaligus dalam satu sesi transaksi secara efisien.

🚀

Auto-Redirect Role Guard

Pengguna yang sudah login secara otomatis diarahkan ke dashboard perannya masing-masing tanpa harus kembali ke landing page secara berulang-ulang.
